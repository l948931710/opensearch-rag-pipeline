# 产品编号对照表 · 填写说明（发 PMC）

> 发起：AI 系统组 · 对接人：张师良 · 交付：填好的表格发回张师良（Excel 或 CSV 均可）

## 一、这是在做什么（为什么值得花这半天）

我们正在给「钉钉直接查产品、算箱规」的功能做上线前的**考试题**。

系统上线后要能认得各种编号——U8 存货编码、客户自己叫的货号、老的作废编号——并且认对是哪个产品。**这张表就是标准答案**：你们把「哪个编号 = 哪个产品」标出来，系统先闭卷考试；**一道都不许认错**（认错编号=后续算错箱规、报错库存，比查不到严重得多），考过才允许它自动认编号，考不过就保持每条都人工确认。

所以：**标注质量直接决定系统敢不敢自动、以及你们以后省多少事。**

## 二、先记住一件事：一行 = 一条「编号 → 产品」的对应关系

**不是一行一个产品。** 同一个产品可以占好几行：它的 U8 编码一行、客户货号一行、旧编码一行。作废/手误的编号也要占一行（答案留空）。

## 三、每列怎么填

| 列 | 填什么 | 要点 |
|---|---|---|
| `namespace` | 编号出自哪个体系 | `u8` = U8 存货编码；`customer:客户名` = 该客户自己的货号（如 `customer:KFC`）；`supplier:供应商名` = 供应商料号 |
| `raw_code` | 编号本身 | **原样照抄**，大小写、空格、横杠、后缀一律不要顺手规整——系统就是要学会认「原始长相」 |
| `expected_ref` | 这个编号指的产品的**统一身份号**（FLP-P-xxxxxx） | 从我们提供的《产品对象清单》里抄；**故意留空 = 这个编号不该对应任何产品**（作废编号、手误编号） |
| `title`（选填） | 产品品名 | 填了可以让系统连「按名字找产品」也一起考 |
| `object_type`（选填） | product / sku | 与 title 配套填 |
| `备注`（选填） | 任何说明 | **拿不准的一定写备注、不要猜**，也不要用留空表达「不确定」（留空有专门含义）——拿不准的行我们一起核 |

## 四、示例（同一个产品占三行，就长这样）

```csv
namespace,raw_code,expected_ref,title,object_type,备注
u8,LX620-50,FLP-P-000123,龙虾杯620,product,
customer:KFC,KH-A88,FLP-P-000123,龙虾杯620,product,KFC 的叫法
u8,LX620-50M,FLP-P-000456,,,改模件，是另一个产品
u8,LX999-旧,,,,2024 年已作废
```

## 五、抽多少、抽什么（总量 50–100 行）

- 三个品类（吸塑/注塑/纸制）各占约 1/3；
- **必须包含难题**（系统最容易错的就是这些）：
  - 改模后缀对（`-M/-N/-W` 结尾的）≥ 5 行；
  - 名字很像但不是同一个东西的 ≥ 5 行（如"黑色注塑叉子/勺子"式近名）；
  - 客户货号 ↔ U8 编码的跨体系对应 ≥ 10 行；
- **必须包含答案留空的负例 ≥ 10 行**（作废编号、写错的编号、别家体系混进来的编号）；
- 其余按日常被问得最多的编号自然抽，**不要只挑干净好认的**——考题太简单，考试就没意义。

## 六、填写纪律（三条）

1. **raw_code 原样照抄**，不规整；
2. **留空只用于「确认不该有对应」**，不确定的写备注；
3. FLP 号只从我们提供的《产品对象清单》里抄，不要手编。

## 七、流程与时点

1. 你们先交 4.1 那张产品参数表（含新增的杯高/口径/嵌套间隙）→ 我们导入系统，回给你们《产品对象清单》（品名 ↔ FLP 号对照）；
2. 对照清单填本表（50–100 行，预计半天）；
3. 发回张师良 → 系统闭卷考试 → 结果（哪类认得好、哪类还得人工）会同步给你们，作为自动化开关的依据。
